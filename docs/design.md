# 匿名聊天室：畫面設計

> 這份文件是 `/design` 的結果整理，給「做前端的人」照著做。
> 規格（有什麼、會做什麼）以 `docs/architecture.md` 第 7 節為準；這份只補「長什麼樣子」，以及設計時新增的兩個功能（第 6 節）。
> 設計稿（可以放大看每個畫面）：https://claude.ai/artifact/JdXAm3EUSZtcd1aSTB17c1 （目前只有擁有者看得到）

---

## 1. 整體方向

- **淺色、溫和、簡潔**，主色是淡紫。
- **手機優先**：先做 390 px 寬的手機版，電腦版是同一套元件在寬螢幕上的排法（見第 5 節）。
- 不用 emoji 當圖示；圖示一律是線條 SVG（見 2.5）。

## 2. 設計基礎（Design tokens）

做前端時請把這些寫成 CSS 變數，不要在元件裡直接寫色碼。

### 2.1 顏色

| 變數名稱（建議） | 色碼 | 用在哪裡 |
|---|---|---|
| `--bg` | `#F5F2FB` | 畫面底色（預設；成員可以自己換，見 6.1） |
| `--surface` | `#FFFFFF` | 頂部列、輸入區、別人的訊息泡泡、對話框、卡片 |
| `--ink` | `#2A2535` | 主要文字；管理員標記、短暫提示、「有新訊息」按鈕的底色 |
| `--muted` | `#6A6280` | 次要文字：時間、系統訊息、說明文字 |
| `--line` | `#E4DEF2` | 分隔線、泡泡邊框、頂部列下緣 |
| `--line-strong` | `#D3C9EA` | 輸入框邊框、收回訊息的虛線框 |
| `--accent` | `#7C5CC4` | 主要按鈕（進入、送出、啟用通知、完成） |
| `--accent-disabled` | `#A994DC` | 「進入中…」這種處理中的按鈕 |
| `--link` | `#6A4BB3`（滑過 `#4F3590`） | 網址連結、`@代號` 的文字色 |
| `--mine` | `#E9E0FA`，邊框 `#D8CBF3` | 自己的訊息泡泡 |
| `--mention-chip` | `#ECE4FB` | 訊息裡 `@代號` 的底色 |
| `--mention-row` | `#FBE6F4` | 「@ 到我」的整則訊息底色 |
| `--tint` | `#F1EBFC` | 選取中的列（@ 選人清單）、編輯中的訊息、編輯提示列 |
| `--disabled-bg` / `--disabled-ink` | `#E4DEF2` / `#8C85A0` | 不能按的按鈕 |
| `--danger` | `#A3261A` | 刪除、踢出、收回、傳送失敗、錯誤文字 |
| `--danger-bg` | `#FBE9E7`，邊框 `#E2B7AF` | 錯誤訊息區的底色、「重試」「踢出」小按鈕的邊框 |
| `--warn-bg` / `--warn-ink` | `#FFF1D6` / `#6B4300` | 連線狀態條（斷線、重連中） |
| `--ok-bg` / `--ok-ink` | `#E3EFE6` / `#24583A` | 通知「已啟用」 |
| `--demo-bg` / `--demo-ink` | `#E7DFF6` / `#463A63` | 示範模式提示條 |
| `--scrim` | `rgba(42,37,53,0.42)` | 對話框、選單後面的半透明遮罩 |
| `--viewer-bg` | `#15131C` | 圖片檢視的全螢幕底色 |

**頭像顏色**：每個人一組淡底深字，用代號算出固定的一組（同一個人永遠同色）。設計稿用了這幾組：
`#E6E1F5/#4A3D7A`、`#DCEBE3/#2F5B45`、`#D7E6F0/#24516B`、`#F3E0E0/#7A2E2E`、`#E9E0FA/#5A3F9E`。管理員固定是 `--ink` 底白字。

### 2.2 字體

- 字型：**Noto Sans TC**（Google Fonts，400／500／700），備用 `system-ui, sans-serif`。
- 字級：

| 用途 | 大小 | 粗細 |
|---|---|---|
| 進入畫面標題 | 30px | 700 |
| 管理員登入／被踢出標題 | 24–26px | 700 |
| 對話框標題、頂部列聊天室名稱 | 18–20px | 700 |
| 輸入框文字、主要按鈕 | 16–17px | 400／700 |
| 訊息內文 | 15px，行高 1.55 | 400 |
| 代號 | 13px | 700 |
| 時間、系統訊息、說明 | 12–13px | 400／500 |
| 管理員標記 | 11px | 700 |

### 2.3 圓角

| 元件 | 圓角 |
|---|---|
| 主要按鈕、輸入框 | 14px |
| 訊息泡泡 | 16px，**靠說話者那一角**改成 4px（別人的在左上、自己的在右上） |
| 手機輸入框、送出鈕 | 22px（膠囊形） |
| 下方滑出的選單／對話框 | 上方兩角 22px |
| 置中對話框 | 20px |
| 標記、短暫提示、「有新訊息」 | 999px（膠囊形） |

### 2.4 間距與尺寸

- 可以點的東西至少 **44×44 px**（手機上一定要做到）。
- 手機畫面左右留白 14px（聊天區）／20–28px（表單類畫面）。
- 訊息之間距離 14px（電腦 16px）。
- 頂部列高 60px；頭像 32px（手機）／36px（電腦、名單）。

### 2.5 圖示

線條圖示，24×24 的 viewBox，`stroke-width: 1.8`，圓角端點，顏色跟著文字（`currentColor`）。
用到的：線上人數（兩個人）、調色盤、鈴鐺、離開（門＋箭頭）、圖片、送出、✕、往下箭頭、重新整理、驚嘆號圓圈、鉛筆（編輯）、返回箭頭（收回）、垃圾桶、踢人（人＋✕）、盾牌（管理員）、分享、加號方塊、勾勾。
建議直接用現成圖示庫（例如 Lucide），風格一致。

## 3. 共用元件

| 元件 | 樣子 |
|---|---|
| **頂部列** | 白底、下緣一條 `--line`。左：聊天室名稱。右（手機）：👥人數按鈕、調色盤、鈴鐺、「離開」文字按鈕 |
| **連線狀態條** | 頂部列下方，高 34px，`--warn-bg`，重新整理圖示＋「連線中斷，正在重新連線…」。只在斷線或重連時出現 |
| **別人的訊息** | 頭像＋（代號、[管理員標記]、時間）＋白色泡泡 |
| **自己的訊息** | 靠右、沒有頭像和代號，`--mine` 泡泡；下方小字：時間（修改過的前面加「已編輯 ·」） |
| **傳送中** | 自己的泡泡半透明（opacity 0.6），下方「傳送中…」 |
| **傳送失敗** | 泡泡下方紅字：驚嘆號＋「傳送失敗」＋膠囊形「重試」按鈕 |
| **收回／刪除後** | 頭像＋虛線框灰字：「小明 收回了一則訊息」／「此訊息已被管理員刪除」 |
| **系統訊息** | 置中灰色小字一行：「小明 進入了聊天室」「星期五 離開了聊天室」「路人甲 被請出聊天室」 |
| **日期分隔線** | 左右兩條細線夾著日期：「10月17日 星期六」；今天寫「今天」 |
| **@ 提及** | `@代號` 用 `--link` 粗體＋`--mention-chip` 底。@ 到自己的整則訊息加 `--mention-row` 底色，左右滿版 |
| **圖片縮圖** | 放在泡泡裡，寬 200px、圓角 10px，可以加一段文字在下面 |
| **「有新訊息 ↓」** | 黑色膠囊按鈕，浮在輸入區上方置中 |
| **輸入區** | 白底、上緣一條線。圖片按鈕＋膠囊形文字框＋送出鈕。沒內容時送出鈕灰掉 |
| **下方選單（手機）** | 遮罩＋從下方滑出的白色面板，頂端一條小把手。危險的選項用紅字 |
| **置中對話框** | 白底圓角 20px，標題＋兩個並排按鈕（左「取消」灰、右確定色） |
| **短暫提示** | 黑色膠囊，在頂部列下方置中，幾秒後消失 |
| **錯誤訊息區** | `--danger-bg` 底、紅字、驚嘆號圖示，圓角 12px |

## 4. 各畫面（對照設計稿的畫板）

| 畫面 | 畫板 | 重點 |
|---|---|---|
| 進入畫面 | `Main` | 最上方示範模式提示條（只在階段一）。圖示＋「匿名聊天室」＋「取一個代號就能聊，不用註冊、不用登入。」。代號框下方左邊「已自動填入上次的代號」、右邊「2 / 16」字數。錯誤訊息區在按鈕上方。按鈕下方「按 Enter 也可以進入」 |
| 進入按鈕／錯誤狀態 | `EntryStates` | 按鈕三態：可按、不能按（代號空白）、「進入中…」。錯誤五種：代號重複、特殊符號、暫時被踢（附時間）、永久被踢、網路問題 |
| 聊天室主畫面 | `Chat` | 頂部列、連線狀態條、訊息列表（由下往上排）、「有新訊息 ↓」、輸入區 |
| @ 選人＋圖片預覽 | `Compose` | 打 `@` 後在輸入區上方浮出清單，標題「線上的人 · 符合「小」」，選中的那列有 `--tint` 底。圖片預覽 76×76，右上角黑色圓形 ✕ |
| 編輯模式 | `Edit` | 被編輯的那則訊息加 `--tint` 底。輸入區上方一條提示列「正在編輯，按 Esc 取消」＋手機版的「取消」按鈕。接近 500 字時在文字框右下顯示紅字「剩 18 字」 |
| 長按自己的訊息（手機） | `OwnMenu` | 被按住的泡泡浮起來；下方選單：編輯、收回（紅）、取消 |
| 管理員長按別人的訊息（手機） | `AdminPhone` | 選單最上面一行「[管理員] 對 路人甲 的訊息」；刪除（紅）、踢出此人（紅）、取消 |
| 線上名單（手機） | `OnlineList` | 從右側滑出、寬 304px。標題「線上 5 人」＋✕。說明「點一下名字，就會在輸入框插入 @代號」。管理員排第一、自己第二（加「（你）」） |
| 聊天背景顏色 | `Theme` | 見 6.1 |
| 圖片檢視 | `ImageViewer` | 深色全螢幕；左上傳圖者與時間，右上圓形 ✕；圖片置中滿版寬；下方「兩指縮放・點背景關閉」 |
| 通知設定 | `Notify` | 下方滑出面板。三個選項卡片（選中的有紫色框和淡紫底），「只有 @ 我（預設）」的說明會帶入自己的代號。分隔線下是「在這台裝置啟用通知」按鈕和說明 |
| 通知被封鎖／iPhone | `NotifyHelp` | 兩張卡片：被封鎖時的 3 個步驟；iPhone 加到主畫面的 3 個步驟（分享 → 加入主畫面 → 從主畫面打開） |
| 管理員登入 | `AdminLogin` | 左上「‹ 回到進入畫面」。盾牌圖示（`--ink` 底）＋標題＋說明；Email、密碼、「登入」（`--ink` 色按鈕，和一般使用者的紫色區分） |
| 被踢出（暫時） | `Kicked` | 置中：圖示＋「你已被請出聊天室」＋白卡片寫「可以再進來的時間／今天 20:45／大約 59 分鐘後」＋「回到進入畫面」連結 |
| 被踢出（永久） | `KickedForever` | 紅色禁止圖示＋「你已被永久請出聊天室」＋「管理員已經禁止你再進入這個聊天室。」，沒有按鈕 |
| 確認對話框與提示 | `Dialogs` | 確認收回、確認刪除、踢出（見 6.2）、確認離開；短暫提示：「太快了，請稍等幾秒」「圖片太大，請換一張小一點的」「只能傳圖片檔」 |

## 5. 電腦版的差異

設計稿畫的是管理員視角（`Desktop`）。

- **版面**：頂部列滿版；下面左邊是聊天區、右邊固定線上名單（約 260px 寬，左邊一條分隔線）。內容最寬 1440px。螢幕變窄時名單會掉到聊天區下方（用 `flex-wrap`），所以不需要另外寫一套。
- **頂部列**：左「匿名聊天室」＋「5 人在線」；右「[站長][管理員]」、「背景」、「通知」、「離開」（圖示＋文字）。
- **滑鼠移到訊息上**：那則訊息有淡色底，右上角浮出小工具列。
  - 自己的訊息：「編輯」「收回」
  - 管理員看別人的訊息：「刪除」「踢出此人」（紅字）
- **線上名單**：每一列右邊有「踢出」小按鈕（只有管理員看得到）。
- **輸入區**：一個大圓角框包住圖片按鈕、文字框、送出鈕；框內提示「輸入訊息…（可以直接貼上截圖，或把圖片拖進來）」；下方小字「Enter 送出・Shift + Enter 換行・打 @ 選人」。
- 進入畫面、圖片檢視、各種對話框在電腦上沿用手機版版面，置中顯示（對話框最寬約 400px）。

## 6. 設計時新增的功能（`architecture.md` 還沒有）

### 6.1 每個人自己選聊天背景顏色

- 入口：頂部列的調色盤按鈕（電腦版是「背景」）。
- 下方面板「聊天背景」，說明「只會改變你自己看到的畫面，別人看不到。」
- 8 個選項，4 欄排列：淡紫（預設 `#F5F2FB`）、薄荷 `#E8F1EC`、天空 `#E7EFF6`、蜜桃 `#FBEDE6`、米白 `#F6F2EC`、奶油 `#F5F0D8`、石灰 `#ECEAE6`、自訂（打開瀏覽器的選色器）。選中的有粗黑框＋勾勾。
- 選了就立刻套用到背景（使用者可以馬上看到效果），按「完成」關閉。
- 只改 `--bg`；泡泡、頂部列、輸入區都是白底，不受影響。
- 存在這台裝置（`localStorage`），不需要上傳到伺服器。

### 6.2 管理員可以選暫時或永久踢出

踢出對話框改成兩個選項卡片：
- **暫時踢出**（預設選中）：「時間到了就可以再進來」，下面選 1 小時／24 小時／7 天。
- **永久踢出**（紅字）：「再也不能進來，之後可以在後台解除」。
- 確定按鈕是紅色。

被永久踢出的人：進入畫面顯示錯誤「你已被永久請出聊天室，無法再進來」；如果正在聊天中被踢，切到 `KickedForever` 畫面。

## 7. 還沒決定的事

1. **永久踢出擋不完全**：不用登入的聊天室，被踢的人換代號或換瀏覽器就可能再進來。要接受這個限制，還是另外想辦法？（要動到 `architecture.md` 第 9 節）
2. **解除永久踢出**：對話框寫「之後可以在後台解除」，但目前沒有設計這個後台畫面。
3. **自訂背景太深**：灰色小字（時間、系統訊息）在深色背景上會看不清楚。選項：只允許淺色，或背景太深時自動把這些字換成淺色。
4. **圖片大小上限**：提示只寫「圖片太大」，還沒決定幾 MB。
5. 「只能傳圖片檔」這則提示是設計時加的，規格裡沒有。
6. 聊天室名稱暫時叫「匿名聊天室」，設計稿裡的代號、訊息都是範例。
